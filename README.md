# JOYING-ZLINK-APK
These are APKs that were pulled from my RAV4 headunit.   JY-TT186N4.
https://www.joyingauto.com/joying-9-inch-toyota-rav4-2013-2018-aftermarket-radio-build-in-dsp-and-spdif.html

This contains both ZLINK5 and ZLINK6.

If you wish to pull these yourself, JOYING has firmware in their blog posts - https://www.joyingauto.com/blog/. You can download the firmware, open preload-apk and the ZLINK file will be in there. Be sure to match your screen resolution and even the branch of ZLINK. Mine is "quzhida" for reference.
